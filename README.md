# TableSnap — Web Table & Data Extractor to Excel / Markdown

Chrome / Edge Manifest V3 extension, 100% client-side. Detects tables, ARIA grids and lists on the active page and exports them as Excel-ready CSV, Markdown (for AI tools, notes and docs) or TSV for free; Pro (LemonSqueezy one-time license) adds multi-sheet XLSX, JSON, data cleaning and per-site presets.

```
src/                    extension (the only folder that gets packaged)
  manifest.json         MV3, permissions: activeTab, scripting, storage
  config.js             CHECKOUT_URL, STORE_REVIEW_URL, LemonSqueezy IDs …
  background.js         silent 7-day license re-validation
  content/content.js    on-demand detector + page highlighting
  popup/                UI
  lib/tablecore.js      parsing, CSV/TSV/Markdown/JSON, cleaning (DOM-free, unit-tested)
  lib/xlsx-lite.js      dependency-free .xlsx writer
  lib/license.js        LemonSqueezy activate/validate/deactivate
  _locales/             en it es de fr pt (generated by scripts/generate_locales.py)
scripts/                build.py, generate_assets.py, generate_locales.py, telegram_report.py
tests/                  unittest suite (+ tests/js run via Node, tests/harness for manual UI checks)
docs/                   GitHub Pages landing + privacy policy
cloudflare-worker/      LemonSqueezy order_created → Telegram webhook
store_assets/           1280×800 promo images + 440×280 tile
```

Build (Windows/macOS/Linux):

```bash
python scripts/build.py
```

Output: `dist/tablesnap-store-ready.zip`. See [DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md) for store submission, LemonSqueezy, Telegram and Cloudflare setup.
