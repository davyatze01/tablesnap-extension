How it works

  1. Install TableSnap from the Chrome Web Store or Edge Add-ons and pin it to the toolbar.
  2. Open any page with a table (Wikipedia, statistics portals, dashboards, price lists…) and click the TableSnap icon.
  3. Hover a result to see it highlighted on the page, or click the eye icon for a preview.
  4. Click CSV, MD or TSV. The file downloads or the table is copied — ready for Excel or your AI chat.

FAQ

Does TableSnap send my data anywhere?

No. Tables are read and converted inside your browser. TableSnap has no servers and no analytics. The only network call is license activation/validation with LemonSqueezy, and only if you buy Pro. See the privacy policy.

Why does Excel show everything in one column?

Your Excel uses a different list separator. In the popup set “CSV separator” to the other option (comma or semicolon). “Auto” picks the right one for your browser language.

Which permissions does it need?

activeTab (read the current tab only after you click the icon), scripting (inject the table detector on that tab) and storage (your settings). No “read all websites” permission.

On how many browsers can I use Pro?

Each license includes several activations (see the product page). Use “Remove license” in the popup to free a slot.
